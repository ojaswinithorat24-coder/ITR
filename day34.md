Day 34

Today, I worked on integrating the RAG backend with the web application. The mentor explained how APIs are used for communication between the frontend interface and the backend services. I observed how a user's question is sent through an API request, processed by the RAG pipeline, and then returned to the frontend with an AI-generated response.

I studied the structure of API requests and responses and understood the JSON format used for data exchange. During testing, I verified whether the user's query was successfully reaching the backend and whether the retrieved context was correctly passed to the language model before generating the final response.

I also performed multiple test cases using different types of questions to evaluate the quality of the generated answers. Some responses were highly accurate, while others required improvements because the retrieved context was incomplete. My mentor explained that retrieval quality directly impacts the final answer generated by the AI model.

Later, I helped identify minor issues related to response formatting and discussed possible improvements for enhancing user experience. I documented my observations for future implementation.

Learning Outcome:

Learned API integration in a RAG application.
Understood JSON-based communication.
