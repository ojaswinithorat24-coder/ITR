# Day 6 Internship Learning

Today, I learned the fundamentals of JavaScript, including its history, statements, variables, data types, and variable declaration keywords.

## History of JavaScript

JavaScript was created by Brendan Eich in 1995 at Netscape. It was initially developed to add interactivity to web pages and has now become one of the most widely used programming languages for web development.

## JavaScript Statements

A statement is an instruction that tells JavaScript to perform a specific action. Multiple statements together form a program and are executed line by line.

## Variables

Variables are used to store data values that can be used and modified throughout a program. They help manage and manipulate information efficiently.

## Data Types

JavaScript supports different types of data:

* String – stores text values
* Number – stores numeric values
* Boolean – stores true or false values
* Undefined – a variable declared without a value
* Null – represents an empty value
* Object – stores data in key-value pairs
* Array – stores multiple values in a single variable

## Variable Keywords

### var

The traditional way of declaring variables. It allows redeclaration and has function scope.

### let

Introduced in ES6. It allows updating values but does not allow redeclaration within the same scope.

### const

Used for values that should not be reassigned after declaration. It provides better code safety and readability.

## Outcome

Through these concepts, I gained a basic understanding of JavaScript and learned how data is stored and managed using variables and different data types.
