# Day 9 Internship Learning

Today, I learned about Objects and Functions in JavaScript. These concepts help organize data and make code reusable.

## Introduction to Objects

Objects are used to store related information in the form of key-value pairs.

### Example

Student Object:

* Name: Ojaswini
* Age: 19
* Course: Computer Technology

In an object, "Name", "Age", and "Course" are properties, while their corresponding values store the actual data.

### Topics Covered

* Creating objects
* Accessing object properties
* Adding new properties
* Updating object values
* Dot notation and bracket notation

## Object Methods

Functions can also be stored inside objects. Such functions are called methods.

### Example

A student object can have:

* Name: Ojaswini
* Age: 19
* greet() → Displays a welcome message

This allows objects to store both data and actions together.

## Functions in JavaScript

Functions are reusable blocks of code used to perform specific tasks.

### Topics Covered

* Function Declaration
* Function Calling
* Parameters
* Arguments
* Return Statement

### Examples

Function to display a message:

* Input: Hello
* Output: Hello

Function to add numbers:

* Input: 10, 20
* Output: 30

Function to calculate square:

* Input: 5
* Output: 25

## Advantages of Functions

* Reduces code repetition
* Improves readability
* Makes code easier to maintain
* Helps organize large programs

## Relationship Between Objects and Functions

Objects are used to store data, while functions perform operations on that data.

### Example

Student Object:

* Name: Ojaswini
* Marks: 90

Function:

* Calculate Grade

Output:

* Grade A

## Outcome

Today’s learning helped me understand how objects organize information and how functions allow code to be reused efficiently. I also learned how objects and functions work together to build structured JavaScript applications.
