Day 15 – Internship Diary (React JS & Node JS + Project Setup)

Today I was not present for the internship session, but I went through the topics covered in that day on my own to stay updated with the progress. The session mainly focused on introducing React JS and Node JS, along with basic project setup and folder structuring.

I learned that React JS is a frontend JavaScript library used to build interactive user interfaces using reusable components. I understood the basic idea of components, props, and state, which help in managing data and UI in a structured way. React makes it easier to build single-page applications with better performance and organization.

I also learned about Node JS, which is used for backend development. It allows JavaScript to run on the server side and helps in handling requests, responses, and backend logic. It is commonly used with Express JS to create APIs and manage server operations.

As part of practice, I created a basic project folder structure to understand how real projects are organized. I made separate folders such as:

frontend/ – for React JS files
backend/ – for Node JS server code
components/ – for reusable UI components
pages/ – for different screens or routes
assets/ – for images, CSS, and other static files

This helped me understand how professional full-stack projects are structured and how frontend and backend are separated but connected.

Overall, today’s learning helped me understand the basics of React JS and Node JS along with proper project folder structure used in real-world applications.
