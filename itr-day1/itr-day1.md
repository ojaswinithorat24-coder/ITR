every thing we learn on day 1 of our internship step by step

Open Visual Studio Code and create or open the project folder you want to upload

Ensure your project has the necessary files (e.g., an index.html file)

2. Create a GitHub Repository
Log in to your GitHub account. If you don't have one, you will need to create it first
Click the "+" icon or the "New" button to create a new repository
Enter a Repository name (e.g., "Demo") and provide an optional description
Click "Create repository"
Copy the URL of the newly created repository

3. Initialize and Commit in VS Code
In Visual Studio Code, click on the Source Control icon (the branch icon) in the left-hand sidebar
Click the "Initialize Repository" button
Enter a commit message in the text box (e.g., "demo") and click the Commit button

4. Connect VS Code to GitHub (Add Remote)
Click on the three dots (...) (More Actions) at the top of the Source Control section
Select Remote and then click Add Remote
Paste the GitHub repository link you copied earlier and press Enter
Enter a Remote Name (e.g., "testcode") and press Enter again

5. Push the Project
Click the three dots (...) again in the Source Control section
Select Pull, Push and then click Push to...
Select the remote you just created (e.g., "testcode")
Once these steps are completed, your files will be uploaded, and you can refresh your GitHub repository page to see your project online

| Command                       | Use                     |
| ----------------------------- | ----------------------- |
| git --version`               | Check Git installation  |
| git clone <url>`             | Download repository     |
| git status`                  | Check changes           |
| git add .`                   | Add all files           |
| git commit -m "msg"`         | Save changes            |
| git push`                    | Upload to GitHub        |
| git pull`                    | Download latest changes |
| git branch`                  | Show branches           |
| git checkout branch-name     | Switch branch           |
| git checkout -b branch-name  | Create new branch       |
| git merge branch-name        | Merge branch            |
| git remote -v                | Check GitHub connection |
| git log                      | Show commit history     |
| git init                     | Create Git repository   |
