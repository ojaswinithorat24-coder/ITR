## What I Learned

Today, I learned the fundamentals of Python programming, starting from **what Python is** to using some of its most popular libraries.

The session began with an introduction to Python, where I learned that Python is a high-level, interpreted, and easy-to-learn programming language used in web development, data science, artificial intelligence, automation, and many other fields.

Next, I studied Python basics such as variables, different data types, taking user input, displaying output, arithmetic and logical operators, conditional statements (`if`, `elif`, `else`), loops (`for` and `while`), and functions. I also learned about Python's built-in data structures, including lists, tuples, dictionaries, and sets.

After understanding the basics, I learned about **modules**, which allow us to organize and reuse code by importing it into other Python programs.

Finally, I was introduced to **Python libraries**, especially **NumPy** and **Pandas**. I learned that NumPy is used for fast numerical computations and array operations, while Pandas is used for data manipulation and analysis using Series and DataFrames. I also practiced importing these libraries and creating simple arrays and DataFrames.

## Conclusion

Today's session provided a strong foundation in Python programming, covering everything from the basic concepts to powerful libraries like NumPy and Pandas. This knowledge will help me build more advanced Python applications and work with data efficiently during my internship.
