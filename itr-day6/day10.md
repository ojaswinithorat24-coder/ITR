# Day 10 Internship Learning

Today, I learned about important Array Methods and modern JavaScript features such as Array Cloning, Spread Operator, and Destructuring.

## Important Array Methods

Array methods help perform operations on array elements efficiently.

### map()

The `map()` method creates a new array by applying a function to every element of an existing array.

### Example

Input:

* [1, 2, 3, 4]

Operation:

* Multiply each element by 2

Output:

* [2, 4, 6, 8]

### filter()

The `filter()` method creates a new array containing only the elements that satisfy a condition.

### Example

Input:

* [1, 2, 3, 4, 5]

Condition:

* Numbers greater than 2

Output:

* [3, 4, 5]

### forEach()

The `forEach()` method executes a function for every element in an array.

### Example

Input:

* ["HTML", "CSS", "JavaScript"]

Output:

* HTML
* CSS
* JavaScript

## Array Cloning

Array cloning is used to create a copy of an existing array so that changes made to one array do not affect the other.

### Example

Original Array:

* ["HTML", "CSS"]

Cloned Array:

* ["HTML", "CSS"]

Both arrays exist independently.

## Spread Operator (...)

The spread operator is used to expand array or object elements.

### Examples

Array 1:

* [1, 2]

Array 2:

* [3, 4]

Combined Array:

* [1, 2, 3, 4]

The spread operator is also useful for cloning arrays and objects.

## Array Destructuring

Array destructuring allows values from an array to be stored directly in variables.

### Example

Array:

* ["HTML", "CSS", "JavaScript"]

Variables:

* first = HTML
* second = CSS

This makes the code cleaner and easier to read.

## Object Destructuring

Object destructuring allows properties of an object to be extracted into separate variables.

### Example

Object:

* Name: Ojaswini
* Age: 19

Variables:

* name = Ojaswini
* age = 19

## Outcome

Today’s learning helped me understand modern JavaScript features that simplify working with arrays and objects. I learned how to transform data using array methods, create copies of arrays, combine data using the spread operator, and extract values efficiently through destructuring.
