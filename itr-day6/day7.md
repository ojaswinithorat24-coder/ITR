# Day 7 Internship Learning

Today, I learned important JavaScript concepts including string indexing, string methods, truthy and falsy values, operators, and loops.

## String Indexing

String indexing is used to access individual characters in a string. Each character has a position called an index, starting from 0.

Example:

* String: "JavaScript"
* J → Index 0
* a → Index 1
* v → Index 2

## String Methods

JavaScript provides various methods to manipulate strings.

* `toUpperCase()` – Converts text to uppercase.

  * "hello" → "HELLO"

* `toLowerCase()` – Converts text to lowercase.

  * "HELLO" → "hello"

* `trim()` – Removes extra spaces.

  * " hello " → "hello"

* `slice()` – Extracts part of a string.

  * "JavaScript" → slice(0,4) = "Java"

## Truthy and Falsy Values

### Falsy Values

Values that are treated as false:

* false
* 0
* ""
* null
* undefined
* NaN

### Truthy Values

Values that are treated as true:

* "Hello"
* 1
* 100
* []
* {}

For example, a non-empty string like "JavaScript" is truthy, while an empty string "" is falsy.

## Operators

### Arithmetic Operators

Used for calculations.

* 10 + 5 = 15
* 10 - 5 = 5
* 10 * 5 = 50
* 10 / 5 = 2

### Comparison Operators

Used to compare values.

* 10 > 5 → true
* 10 < 5 → false
* 10 == 10 → true

### Logical Operators

* true && true → true
* true || false → true
* !true → false

## Loops

### for Loop

Used when the number of repetitions is known.

Example:
Print numbers from 1 to 5.

Output:
1 2 3 4 5

### while Loop

Repeats while a condition is true.

Example:
Print numbers from 1 to 3.

Output:
1 2 3

### do...while Loop

Executes at least once before checking the condition.

Example:
Print number 1.

Output:
1

Today’s learning helped me understand string handling, built-in string methods, truthy and falsy values, different types of operators, and the use of loops for repetitive tasks in JavaScript.
